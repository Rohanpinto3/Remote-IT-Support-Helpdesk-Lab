# Remote-IT-Support-Helpdesk-Lab


A hands-on IT support lab focused on remotely connecting to and troubleshooting Windows systems using common remote support tools.

This project demonstrates practical remote support skills used in Help Desk and IT Support environments.

---

## 🧪 Labs

| Lab                                                            | Description                                                                                  |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 🖥️ [01 - Windows Remote Desktop](./01-Windows-Remote-Desktop) | Configure and use Windows Remote Desktop (RDP) for remote system access and troubleshooting. |
| 🖥️ [02 - AnyDesk Remote Support](./02-AnyDesk-Remote-Support) | Use AnyDesk to establish a remote support session and troubleshoot a Windows system.         |

---

## 🎯 Skills Practiced

* Remote desktop connectivity
* Windows Remote Desktop (RDP)
* AnyDesk remote support
* Windows troubleshooting
* Remote user assistance
* Basic network connectivity troubleshooting
* Secure remote-access practices
* Verifying remote connections

---

## 🛠️ Tools

* Windows 10/11
* Windows Remote Desktop
* AnyDesk
* VirtualBox

---

## 📋 What I Practiced

* Connecting to a Windows machine remotely using RDP
* Configuring Windows Remote Desktop
* Connecting to a user machine through AnyDesk
* Testing remote access and connectivity
* Performing basic troubleshooting through a remote session
* Ending and verifying remote sessions

---

## 🎯 Objective

Practice the basic remote-access tasks used in Help Desk and IT Support, including connecting to user systems and troubleshooting Windows issues remotely.
